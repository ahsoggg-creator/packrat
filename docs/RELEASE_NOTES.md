## Packrat 0.1.0 — все ядра, умная распаковка, безопасные пути

Первый выпуск: ядро форматов, «умная» распаковка и окно с деревом архива. Те же возможности есть в `packrat-cli`.

- **Форматы.** ZIP (store, deflate, zstd) и TAR (`.tar`, `.tar.gz`, `.tar.zst`, `.tar.xz`, `.tar.lz4`) читаются и пишутся; 7z (без пароля; LZMA2, BZip2 и PPMd проверены на архивах 7-Zip, остальные методы — средствами библиотеки) читается, создаётся 7z с LZMA2; одиночные `.gz`, `.bz2`, `.xz`, `.zst`, `.lz4` открываются как архив из одного файла. Всё на чистом Rust, без нативных библиотек сжатия. RAR не поддерживается: лицензия распаковщика unrar не позволяет включать его в программу.
- **Все ядра.** Записи ZIP и блоки больших файлов сжимаются параллельно (deflate — независимыми блоками, zstd и lz4 — независимыми кадрами, 7z — параллельными солидными блоками LZMA2); записи ZIP распаковываются параллельно. Число потоков настраивается. Измерено на 400 МБ (8063 файла): создание ZIP/deflate 7,4 с → 1,6 с (4,6×), ZIP/zstd 5,5 → 1,7 с (3,2×), TAR.ZST 5,5 → 1,9 с (2,9×), 7z 221 → 85 с (2,6×). Распаковка на этом наборе почти не ускоряется (9,2 → 8,2 с): время определяет создание 8 тысяч файлов при включённом Защитнике. Методика и все числа — в `docs/BENCHMARKS.md`.
- **Умная распаковка.** Один корневой каталог — прямо в выбранную папку, без `Папка\Папка`; один файл — рядом; несколько элементов россыпью — в папку с именем архива. Работает с записями `./` и каталогами, различающимися только регистром. Покрыто тестами.
- **Без молчаливой перезаписи.** Сначала строится план: существующие файлы показываются до начала распаковки, по умолчанию они пропускаются; можно заменить или сохранить под новым именем (`имя (2).txt`).
- **Безопасные пути.** Записи с `..`, абсолютными путями, буквами дисков, UNC, зарезервированными именами Windows (`CON`, `NUL`, `COM1`…), альтернативными потоками NTFS, хвостовыми точками и пробелами не распаковываются и попадают в список «заблокировано». Символьные ссылки из архивов не создаются; запись через уже существующую ссылку или junction запрещена (проверено тестом с настоящим junction).
- **Окно.** Дерево архива, сортировка, выбор нескольких записей, распаковка кнопкой и перетаскиванием в Проводник, перетаскивание архива или файлов в окно. Русский интерфейс по умолчанию, английский — в настройках.
- **Установщик и обновления.** `Packrat-Setup.exe` ставит программу для текущего пользователя без прав администратора (ярлык в «Пуск», запись в «Приложения и возможности»). Раз в сутки Packrat спрашивает `api.github.com` о новой версии (можно отключить); обновление скачивается, проверяется по SHA-256 из `SHA256SUMS.txt` и заменяет файл; `Packrat.exe --update` делает то же без окна.
- `packrat-cli`: `list`, `extract` (`--smart`, `--skip`/`--overwrite`/`--keep-both`, `--threads`), `create` (`--format`, `--level`, `--threads`).
- Демо и скриншоты: `Packrat.exe --demo` (выдуманные данные), `Packrat.exe --screenshots <папка>`.

Ограничения: в ZIP не читаются методы deflate64, bzip2 и LZMA; zstd-кодировщик на чистом Rust имеет один уровень (примерно `zstd -1`); список `.tar.*` строится проходом по всему архиву; 7z создаётся только с LZMA2 и без пароля; `.tar.lz4` не открывается стандартным 7-Zip. Автоопределение кодировок имён, защита от архивных бомб, пароли, просмотр файлов внутри архива, меню Проводника и ассоциации — в версиях 0.2.0 и 0.3.0.

**Файлы релиза**

| Файл | Что это |
| --- | --- |
| `Packrat-Setup.exe` | установщик: ставится в `%LOCALAPPDATA%\Programs\Packrat`, права администратора не нужны |
| `Packrat.exe` | переносная версия (тот же файл; установить можно из настроек) |
| `packrat-cli.exe` | консольная версия: `list`, `extract`, `create` |
| `SHA256SUMS.txt` | контрольные суммы |

**Что важно знать**

- Права администратора не нужны ни для установки, ни для работы: в этой версии нет функций, которым они требовались бы.
- Исполняемые файлы не подписаны: SmartScreen может показать предупреждение «неизвестный издатель» («Подробнее» → «Выполнить в любом случае»). Сверьте файл с `SHA256SUMS.txt`.
- Никакой телеметрии. Единственный сетевой запрос — проверка новой версии на GitHub (отключается в настройках). В журнал не пишутся пароли, имена файлов из архивов и их содержимое.
- Не проверено на реальной системе: сам жест перетаскивания мышью из окна в Проводник (объект данных CF_HDROP проверен тестом) и установка в настоящий профиль пользователя — установка, ярлык, запись в реестре и удаление проверены в изолированной папке и ветке реестра (`PACKRAT_SANDBOX`). Автообновление проверено только на разборе ответа GitHub, пины адресов и проверке суммы: настоящего релиза для скачивания до этого выпуска не существовало.

Подробности и ограничения — в [README](https://github.com/ahsoggg-creator/packrat#readme) и [docs/BENCHMARKS.md](https://github.com/ahsoggg-creator/packrat/blob/master/docs/BENCHMARKS.md).
