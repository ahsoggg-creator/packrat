## Packrat 0.5.0 — несколько архивов за раз, компактная распаковка, «Отправить»

- **Выделили много архивов — одно окно.** «Распаковать здесь», «Распаковать в…» и «Проверить» из меню Проводника обрабатывают все выбранные архивы по очереди и дают один итог. Битый архив не останавливает остальные; «Распаковать в…» спрашивает папку один раз.
- **Компактная распаковка из Проводника.** Маленькое окно с прогрессом; после чистой распаковки папка открывается, окно закрывается само. При проблемах остаётся отчёт.
- **Удаление архива после распаковки (по умолчанию выключено).** В корзину, только после полной успешной распаковки всего архива. Если файл нельзя отправить в корзину, Windows спросит про удаление насовсем.
- **«Отправить → Packrat — в архив».** Все выбранные файлы попадают в один архив. Ставится и убирается вместе с меню Проводника.
- **Windows 11.** В «Настройках» — переключатель классического контекстного меню (Packrat виден без «Показать дополнительные параметры»); откат снятием галочки, нужен перезапуск Проводника. Меняет меню для всех программ и остаётся после удаления Packrat.

Проверено тестами и в изолированной ветке реестра; в живом Проводнике и визуально компактное окно не проверялось.

**Файлы релиза:** `Packrat-Setup.exe`, `Packrat.exe`, `packrat-cli.exe`, `SHA256SUMS.txt`. Исполняемые файлы не подписаны (SmartScreen); телеметрии нет, единственный сетевой запрос — проверка новой версии (отключается в настройках).
