## Packrat 0.4.0 — RAR, CAB, ISO, LZH, DEB, CPIO, RPM

- **Новые форматы (только чтение).** RAR (до 5.x, пароли, тома открываются с любой части; через библиотеку unrar), CAB (MSZIP, LZX, Quantum), ISO 9660 (Joliet и Rock Ridge), LZH/LHA, AR/DEB, CPIO (в том числе `.cpio.gz`, `.cpio.xz`) и RPM. Файлы `.jar`, `.apk`, `.docx`, `.epub`, `.cbz` — это ZIP и открываются как раньше.
- **Проводник и ассоциации.** Меню и ассоциации теперь охватывают `rar`, `cab`, `lzh`, `lha`, `cpio`, `deb`, `rpm`, `tbz`, `tbz2`; для `.iso` — только меню (двойной щелчок остаётся за Windows). Диалог «Открыть» знает все форматы.
- **Автообновление.** Запросы к GitHub повторяются до трёх раз, у подключения свой таймаут. Версии 0.1.0 и 0.2.0 обновиться сами не могут (лимит 60 с на скачивание) — установите `Packrat-Setup.exe` вручную.
- Лицензия unrar разрешает поставку, её текст — в `THIRD_PARTY_NOTICES.md`.

Ограничения: RAR только читается; RAR внутри другого архива сначала нужно распаковать; CAB из нескольких файлов, ISO с файлами больше 4 ГиБ, UDF, `.Z` и `.lzma` не поддерживаются. Проверено на реальных файлах: ISO (bsdtar, IMAPI), CAB (makecab), CPIO, AR. RAR, LZH и RPM проверены только на собранных вручную архивах; RAR с паролем не проверялся.

**Файлы релиза:** `Packrat-Setup.exe`, `Packrat.exe`, `packrat-cli.exe`, `SHA256SUMS.txt`. Исполняемые файлы не подписаны (SmartScreen); телеметрии нет, единственный сетевой запрос — проверка новой версии (отключается в настройках).
